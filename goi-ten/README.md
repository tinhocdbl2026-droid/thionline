# Gọi tên học sinh

Bản chia sẻ có dữ liệu học sinh mẫu. Thêm danh sách thật bằng mục DS Học sinh trong ứng dụng.

Chạy trên Windows: cài Node.js >=22.12, mở chạy.bat. Giữ cửa sổ máy chủ mở, Ctrl+C để dừng.

Build: npm ci, npm run build. Bản dist dùng đường dẫn tương đối, phù hợp GitHub Pages.

Không cần khóa API. Danh sách lớp và lịch sử được lưu trong trình duyệt đang sử dụng.
